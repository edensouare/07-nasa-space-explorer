# NASA Space Explorer

Explore NASA's Astronomy Picture of the Day. Choose a date range to browse space photos, then install the app on your phone for quick access.

## Deploy to GitHub Pages

The site deploys automatically whenever changes are pushed to `main`. The GitHub Actions workflow builds the app with Vite and publishes the `dist` folder. The first deployment enables GitHub Pages with the GitHub Actions source.

After the deploy workflow succeeds, visit:

https://edensouare.github.io/07-nasa-space-explorer/

## Install on your phone

Open the deployed site in your phone's browser while connected to the internet:

- **iPhone or iPad:** Open the site in Safari, tap **Share**, then choose **Add to Home Screen**.
- **Android:** Tap **Install app** if prompted. Otherwise, open the browser menu and choose **Install app** or **Add to Home Screen**.

The site must be served over HTTPS to install. On iPhone or iPad, add it to the Home Screen before enabling notifications. The notification button currently sends a test notification; automatic NASA photo alerts are not configured.
